  "6.1 Experimental Setup

  We conduct experiments on the KuaiRec dataset [1], specifically the
  small_matrix (1,411 users × 3,327 items, nearly fully observed) for
  training and evaluation. Experiments span two architectural tracks
  and six model variants (Table 1).

  Track A (ID baselines): A1 is a Baseline MLP and A2 is an ID-only
  Transformer encoder. Both use only learnable ID embeddings.

  Track B (LLM-augmented): B1 and B1-Gen are LLM-enhanced MLPs using
  frozen 384-dimensional sentence embeddings. B2 and B2-Gen are
  LLM-Transformers that fuse LLM embeddings into item input tokens and
  prepend a [USER] prefix token derived from the user LLM embedding.
  The -Gen variants replace raw user profiles (top-20 item descriptions
  concatenated, avg. 583 tokens) with 2-sentence summaries generated by
  Mistral-7B-Instruct (avg. 126 characters, ~60 tokens), fully within
  the sentence encoder's 128-token limit.

  MLP models (A1, B1, B1-Gen) use MSE loss to predict watch_ratio and
  are evaluated on regression metrics. Transformer models (A2, B2, B2-Gen)
  use InfoNCE contrastive loss for sequential next-item ranking and are
  evaluated on ranking metrics (Hit@K). The two loss scales are not
  comparable across tracks.

  All models are trained for 5 epochs, Adam optimizer (lr=0.001),
  batch size 512 for MLP and 64 for Transformer, 90/10 train/validation
  split, random seed=42. watch_ratio is clipped to [0, 5.0]."

  "6.3 Sequential Ranking Performance

  We evaluate A2 (ID-Transformer) and B2/B2-Gen (LLM-Transformer)
  on next-item ranking using InfoNCE contrastive loss. Both models use
  a Transformer encoder (4 attention heads, 2 blocks, hidden_dim=32)
  trained on sequences of up to 150 watched items per user.

  As shown in Table 3, B2 (LLM-Transformer with raw user embeddings)
  substantially outperforms A2 on Hit@10: 0.0080 vs 0.0025, a 220%
  relative improvement. The InfoNCE validation loss also improves from
  8.809 (A2) to 8.521 (B2), a 3.3% reduction. This confirms that
  fusing frozen LLM embeddings into the item input tokens and providing
  a user-LLM prefix token gives the Transformer a semantic signal that
  pure ID-based training cannot recover in 5 epochs.

  token) achieves the same metrics as B2-raw (Hit@10=0.0080, InfoNCE
  =8.521). The Transformer's ranking is dominated by the item token
  sequence; the user prefix contributes less at 5 epochs. This
  contrasts with the MLP regression track, where generative user
  profiles provided the largest individual gain. Longer training is
  expected to widen the gap between B2-Gen and B2-raw."

  with longer training.

  Across tracks, the generative pipeline (Mistral-7B summarization
  followed by sentence-transformer encoding) is the single most
  impactful component for regression quality, validating the
  'Generative AI' framing of the paper title."
